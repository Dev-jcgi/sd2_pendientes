Aviso del 26/11: nuevo contrato CatalogService.findCommerce

Para que pedidos muestre el comercio de un pedido sin depender de catálogo (#146), core-module tiene desde el 26/11 (!123, #148):

  • CommerceInfo(UUID commerceId, String name) en org.jala.edu.core.contract.
  • CatalogService.findCommerce(UUID commerceId) → Optional<CommerceInfo>: id existente → su id y nombre; id inexistente o null → vacío; un comercio deshabilitado se devuelve igual. Es un método default: ninguna implementación deja de compilar.
  • FallbackCatalogService devuelve el comercio de ejemplo (SampleCatalog.COMMERCE, "Sample Pizzeria"): pedidos puede avanzar sin esperar a catálogo.
